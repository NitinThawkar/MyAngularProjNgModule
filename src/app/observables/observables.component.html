observable have 3 callback function Success()Error()Complete() observable is used for handling asynchronous data. It is a part of RxJS library which is included in Angular. it is used to handle multiple values over a period of time. it is used for handling events, asynchronous programming, and handling multiple values. it is used for handling HTTP requests and responses. it is used for handling user input events. it is used for handling real-time data streams. it is used for handling WebSocket connections. it is used for handling animations. it is used for handling forms. it is used for handling routing. it is used for handling state management. it is used for handling dependency injection. observable also support operators like map, filter, concat, merge, etc to manipulate the data before it is passed to the subscriber.
